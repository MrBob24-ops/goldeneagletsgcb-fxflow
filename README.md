# GCB FXFlow — Outward Remittance Prototype

Single-file HTML prototype for a foreign transfer / outward remittance flow.

## Live demo
https://goldeneagletsgcb-fxflow.netlify.app/

## Demo shortcuts
- Account: `1020130045678`
- Phone: `0244123456`
- Email: `ama@example.com`
- Ghana Card: `GHA-123456789-0`
- OTP: `123456`
- Request ID: `TF2026000184`

## Limit states
- `#used=10000` — Outward yearly limit reached
- `#used2=200000` — Advance Payment yearly limit reached
